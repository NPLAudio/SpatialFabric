# Path Studio (design phase)

Planned desktop editor for authoring object, listener and camera paths and previewing
them live in Unreal, Unity and Godot. See [ADR 0001](../../Docs/PathStudio-ADR-0001.md).

**Current contents (Phase 0, no GUI yet):**
- [`pathstudio/model.py`](pathstudio/model.py): standard-library reference validator and
  deterministic sampler for [Path v1](../../Specs/Path-v1.md).
- Hand-computed golden vectors in [`Fixtures/path-v1.json`](../../Fixtures/path-v1.json),
  generated by [`Tools/build_path_fixtures.py`](../../Tools/build_path_fixtures.py).

```sh
python -m unittest discover -s tests -v
```

The model never touches the network, audio devices or a GUI. Future live streaming must be
explicitly armed and never start playback on its own.
